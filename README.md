An entry for the [make.fun](https://make.fun) bounty **"Fortune in a Pot"**
(`u-golden-heron-44-fortune-in-a-pot-ded981e9`): write a single line, at most
120 characters, telling a houseplant's fortune — kind, funny, and
unmistakably about the plant on the windowsill.

## How it works

`main.py` (pure Python standard library, no dependencies) writes the fortune
to `/output/entry.txt`:

> Your fortune, little plant: the sun adores your spot on the sill — expect praise, new leaves, and a bigger pot soon.

Run it with:

```sh
python3 main.py
```
